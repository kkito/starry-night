- [ ] **Step 4: 写最小实现**

`src/lib/dome.ts`：

```ts
export interface DomeVec { x: number; y: number; z: number; }

/** 地平坐标 → 天球直角坐标（北=-z、南=+z、东=+x、天顶=+y）。 */
export function altAzToVec(azDeg: number, altDeg: number, r: number): DomeVec {
  const a = (azDeg * Math.PI) / 180;
  const e = (altDeg * Math.PI) / 180;
  return {
    x: r * Math.cos(e) * Math.sin(a),
    y: r * Math.sin(e),
    z: -r * Math.cos(e) * Math.cos(a),
  };
}

export const DOME_R = 400;
export const TREE_AZ = 110;
export const BUILDING_AZ = 133;
```

```ts
export type ViewMode = '2d' | '3d';

  // ...既有字段
```

`validateView` 追加：

```ts
if (!['2d', '3d'].includes(v.viewMode)) return 'viewMode 无效';
```

`toDraft` / `submit` / `Draft` 同步带上 `viewMode`（`Draft` 的 Omit 映射会自动带，submit 里加 `viewMode: draft.viewMode as ViewMode`）。

`App.tsx`：
1. `DEFAULT_VIEW` 加 `viewMode: '2d'`
2. 顶栏右上角（菜单按钮同行）加切换：

```tsx

  <button aria-label="2D 视图" onClick={() => setView(v => ({ ...v, viewMode: '2d' }))}>2D</button>
  <button aria-label="3D 视图" onClick={() => setView(v => ({ ...v, viewMode: '3d' }))}>3D</button>
```
